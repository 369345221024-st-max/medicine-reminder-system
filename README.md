## ปัญหาและกลุ่มเป้าหมาย
ผู้สูงอายุจำนวนมากประสบปัญหาในการรับประทานยาตามที่แพทย์กำหนดอย่างต่อเนื่อง มักเกิดความสับสนเกี่ยวกับประเภท ขนาดยา และช่วงเวลาการทานยา ส่งผลกระทบต่อประสิทธิภาพการรักษา ขณะที่ผู้ดูแลยังขาดระบบติดตามแบบเรียลไทม์
กลุ่มเป้าหมาย: ผู้สูงอายุในชุมชน และผู้ที่มีโรคประจำตัวที่ต้องทานยาเป็นประจำ

## ฟีเจอร์หลักและขั้นตอนทดสอบ
1. ตั้งเวลาการทานยา (/admin): กรอกชื่อยา ขนาดยา เวลาทานยา แล้วกดบันทึก
2. กดทานยาแล้ว: ป้ายเตือนแสดงเมื่อถึงเวลา กด "กดทานยาเลย" เพื่อบันทึกเวลาลงฐานข้อมูล
3. ดูประวัติการทานยา (/summary): เลือกวันที่ต้องการเพื่อดูประวัติการทานยาย้อนหลัง

## เทคโนโลยีที่ใช้
Vue, Vite, Supabase, Netlify

## วิธีติดตั้งและรัน
1. ติดตั้ง Node.js รุ่น LTS
2. คัดลอก .env.example เป็น .env.local แล้วใส่ค่า VITE_SUPABASE_URL และ VITE_SUPABASE_KEY
3. npm install
4. นำเข้าฐานข้อมูลจาก database/ (ตาราง impact_log)
5. npm run dev แล้วเปิด http://localhost:5173
